# 场景重建与核对记录

更新日期：2026-09-22。

当前场景是基于故事地点重新设计的网页版场景，不是从原版提取的地图。核对依据包括本地现有地图/任务数据、新场景图片的实际地面形状，以及运行中的寻路和交互行为。原版目录仅用于参考事实；本项目场景继续独立设计，不导入原版图像、地图或脚本。地点名称数量不能代替场景匹配度。

## 本轮改动

- 增加 `public/world.mjs`，将边界、出生位置、主线目标、出口、障碍、探索物、道路和道具分开定义。
- 凌绝峰、山下酒肆、洗剑池、武当山门、武当大殿、武当山下分别手工布置。其他地点按悬崖、酒肆、庭院、大殿、山路、树林、洞穴、客房、花园、街巷、水岸、塔层划分。
- 洞中蝙蝠与蝙蝠王改用独立振翅形态，不再套用人类角色图；其他人物仍受现有图集限制。
- 新的背景种类使用 cliff / inn / temple / hall / island / cave / bedroom；保留 forest / lake / town / snow 的必要用途。天池仍使用雪山环境，九曲溪使用林间环境。
- 老板、商人、道士、长者、村民、弟子、蒙面刀客、蔷薇可使用八格NPC图集。身份未知的具名人物保留旧图；红衣少女/陌生女子保留紫轩/月眉儿对应图，八格脚底均按成品实际位置对齐。此图集是角色类型重绘，不是原版肖像。
- 场景对象改为能辨认的墓碑、剑痕、木箱、木牌、草药、桌椅、车、柱、火盆、池、树和书卷。角色与道具按脚下位置排序，能形成前后遮挡。
- 已查看的探索物继续保留在场景里；开启宝箱显示打开的盖子。
- 小地图绘制道路和不可行区域，主画面支持日夜、雨、雪、薄雾和落花。减少动态效果选项会停掉天气粒子。
- 新场景图片尚未加载时显示安全底色；背景与小地图都不会向画布传入不存在的图片。
- 战斗预警使用引擎锁定的落点和攻击范围：圆形的显示半径与 y×1.3 的判定一致，直线按同一空间显示带圆头的攻击带。

## 当前实测规模

以 2026-09-11 的 `getScene` 输出统计：75 个地点，12 个场景类别；按边界、出生、出口、障碍和道具点位去重是 **33 种几何布局**。有 230 个探索点、464 个碰撞矩形（包括地形边界）、351 个场景道具。背景映射使用 11 类环境图片。

这些数值不是“75 张独立原版地图”或“原作还原率”。客房、洞穴、塔层等仍复用底图和部分布局。本轮的230个探索点是网页探索补充，不是经核对的原版支线。

## 验证范围

- 使用实际 `GameEngine` 遍历 75 个地图的出生点。
- 逐个检查 380 处主线目标、出口和探索点：坐标可站立，从该图出生点可寻路到达。修复花园点位后的第二轮和修复视觉尺度后的第三轮、再次抽查后的第四轮均为 0 个失败。
- 道具图集分支以模拟图像对象验证：首六图和已探索状态共执行28次图集绘制，裁切均落在4×2格范围内，道具显示高度不超过92；写实图像效果仍以浏览器实拍为准。
- 界面运行校验覆盖 142 个故事事件，渲染引用/坐标检查通过；菜单启动和对话推进通过。
- NPC分支检查覆盖8个图格、逐格脚底锚点和3种保留角色的化名/姓名；实际PNG尺寸1536×1024核对通过。
- 独立目视查看 cliff / inn / temple / hall / island / cave / forest 的背景图，依据可见地面增加边界遮挡；bedroom 的床、屏风、柜、栏杆和出口坐标由负责该图的代理逐图核对。
- 以上自动检查不能证明剧情与原作相符，也不能替代玩家实际走完每张地图。完整浏览器流程体验由主任务继续核对。

## 仍需补足

1. 只读参考原版或连续游玩录像的空间用途、任务联系与游玩节奏；道路、室内结构和入口布局仍独立设计，不复制资源。
2. 继续将复用的客房、塔层、洞穴和花园拆成更符合事件的独立布局与背景。
3. 对任务所在的具体空间逐段演出：NPC站位、来去路线、入室/下楼/穿门过程，而不是只验证任务ID递增。
4. 角色图集仍有明显复用；本轮的场景对象和寻路改动不等同于人物造型复刻。

## 2026-09-22：开场步行连接与支线岔路

### 已核验机制

参考目录只读核验确认：开场经过峰顶、下山连接路、山下酒肆、洗剑池、登山连接图和武当山顶。酒肆旁还有通往后续旅程的方向；洗剑池守卫未全部击败时不能通行。事实边界见 original-story-evidence.md；没有提取或使用原版地图、台词、图像。

### 原创表现设计

- 保留既有任务编号：m1 凌绝峰、m2 山下酒肆、m3 洗剑池、m4 山门、m5 武当山顶。新增 r_lingjue 与 r_wudang 两张可行走连接图，复用项目现有独立绘制的 forest.png，重新设计路标、歇脚点、出入口与方向描述。
- 开场连续路线为 m1 → r_lingjue → m2 → m3 → m4 → r_wudang → m5。这里保留了网页既有的独立山门任务；m4 在登山连接路之前的布置是本项目设计，尚未实机校准原作地图间次序。
- 出入口分开记录：每图的 portals[邻图] 含 exit 与 entry，两者相隔一段可走距离。上山和下山使用同一条双向路线；下山返回 m2 后，南侧岔路前往 m6 救商人所在的商道。
- 门槛分别采用已完成 a01（离峰）、a02（问路上山）、a03（击败两守卫）、a04（通山门）和 a05（下山沿商道）。路线规划不会因地图出现在 visited 中而跳过门槛。
- 为此前无法首次进入的支线地图建立四条独立设计的岔路：到达 a11 后 m10 客栈 ↔ m72 惠安镇 ↔ m74 北郊；到达 a22 后 m18 清平乡 ↔ m73 小屋；到达 a07 后 m7 野树林 ↔ m75 九曲溪。它们让鱼钩、施舍、对联、和尚及野姜支线具备真实的进入和返回路径；这些相邻关系尚未证明等同于原版地图布局。
- 其余章节暂以已经到达阶段的任务旅程生成相邻边，数据显式标记 inferred。正线、邪线和背弃分支各自过滤，不把互斥任务序列首尾拼接。该结构用于逐步替换旧传送行为，不能视为已核对的全地图拓扑。

### 本轮空间验证与未确认项

- 使用实际 GameEngine.findPath，对 77 图共 448 个出口/入口坐标逐一检查：全部可站立、从出生点精确到达且所有路径段无碰撞穿越。
- 开场 a05 阶段路线包含两段连接图；a03 守卫战前从洗剑池到山顶无通路；a11 能首次走入北郊；a07 能从酒肆往返九曲溪。
- 所有同图出口之间距离至少 145；分开的出生入口可避免跨图后立即重复触发返程。
- 新连接图仍共享森林背景，尚无独立远景；自动空间检查不证明视觉丰富度和原作一致。连续浏览器步行、NPC演出与锁门反馈由运行时集成后实测记录补足。
