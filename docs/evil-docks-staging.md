`requiredAnyFlags` 每组内为 OR，多组之间为 AND。真实前置用实际旗标，历史兼容用明确历史旗标，不用新增 done、claimed 或 staged 伪造过去经历。`evilLegacyDocksPrelude` 只用于旧 e08 已处于 choice/after、尚未 done 的前置演出兼容；旧 talk/travel 仅有海岛历史时仍应播放新的登陆会面。具体旧版本映射与中性历史结果展示由根迁移实现和验证。

e08 仍是网页原有索引0拒绝（evil -3）、索引1动手（evil +3）；同时将另一结果旗标明确置 false。没有改为原记录的 -10/+10，也没有冒称网页累计阈值已完成校准。选项 `after` 及 e08 的 `after` 为空，防止先播放死亡结果再提交答复。两个结果任务自己承担对白和动作，单纯选择不会提前得到倒地或完成标记。

全部新增任务及修正的 e07/e08 明确 `xp:0, money:0`。岛战还有 `suppressBattleSupplies:true`，关闭旧通用两类药各1的补给。`recover:true` 只走一次任务奖励账本，恢复生命、内力、体力，没有新增玉佩、遗书、船票或武功。原版普通战斗是否有其他经验/拾取未全面核定；网页此战没有逐人刷取收益是自己的规则。

## 战斗和同伴

敌人 ID 为 `island-bandit-01` 至 `island-bandit-35` 加 `island-bandit-chief`。同伴为稳定 ID `island-mei`，配置 `criticalAllyIds:['island-mei']`。阵容成员均给独立外观与战斗字段，避免套用武当阵容身份。

本次初始平衡：普通敌人 HP155、tier8；头目 HP1050、tier12；月眉儿 HP4400、tier12。所有成员使用 sword 行为，头目与月眉儿采用有蓄势招式的首领行为。这些完全是网页平衡值，尚需实际战斗验证，不是提取的原版属性。关键友方倒下即本战失败，是依据跟随者死亡回调关系作的网页规则；原版实际失败画面、操作和重试体验仍未实机核定。

站位集中由 `world` 的 `scene.skirmish` 提供，数据模块不再保存另一套坐标：主角 `(400,620)`，月眉儿 `(520,600)`，35普通敌人在右侧六列六行中占35格，头目 `(1260,615)`。运行器按 ID 查找点位，必须拒绝重叠或不完整阵容，并保留武当39敌的旧存档隔离。

岛战前置演员中提前显示头目与月眉儿；居民撤退后交回运行器，演出最终演员隐藏。实际战斗只画阵容单位，防止头目、同伴与装饰角色叠在一起。新旅行任务 `hideCompanion:false`，保证月眉儿能沿禁地逆向道路与后续陆路同行；进入有同名演出人物的场景时由通常演员去重机制接管。

## 临时插叙、码头结果与原创画面

`towerInterlude` 不登记为可旅行地点，现实 `s.map` 保留山路。进入 scene 时不写主角坐标，场景的 `hidePlayer:true` 隐藏主画面、标签与小地图上的主角/同伴。回程步骤为 `scene:null, hero:{restore:true}`，需要恢复本次插叙入口保存的现实坐标与朝向，不能一律拉回地图中心。

孟知秋从 `(620,650)` 走至 `(780,620)`，纳兰从 `(950,480)` 走至 `(930,520)`；双方交手后纳兰倒地，孟退至 `(760,650)`。退出时两名演员都隐藏，`finalActors:[]`，没有永久纳兰尸体、经验、伤害或物品结果。复用的 `dreamFade` 只是现有淡入淡出键，不表示影枫做梦，也不让其得知发生在别处的事。

岛码头五名居民有独立 ID 和站位。送别后主角走至 `(1175,700)`，保留到船出口的最后一段实际步行；不会用演出自动跨地图。离开送别任务后持久演员只保留五名居民，月眉儿恢复普通跟随，避免隐藏的同名演员继续挡住跟随。

中原码头紫轩从内陆方向 `(700,865)` 经 `(820,730)` 接近至 `(900,620)`；主角 `(690,570)`、月眉儿 `(835,525)` 构成对峙。拒绝支月眉儿走到 `(825,650)` 出手；亲手支主角走到 `(800,675)` 出手。紫轩倒地位置相同，持久演员 `interactive:false`，完成旗标与相应 staged 状态共同控制回访展示，不能生成两具尸体或重新出现活人交互。

背景 `island-village.png`、`mainland-dock.png` 由根代理独立制作，地图代理提供碰撞和门户；楼内画面复用项目已有原创 hall。月眉儿使用本轮新作 `mei-original.png`，图内为象牙外衣、深青衣及暗红腰带，按姓名统一供场景与对白渲染。`sprite:2` 仅作为兼容后备：实看旧 characters 图集时该格为紫衣女子，历史上紫轩与月眉儿共用，不能把那个旧图格当作已核月眉儿形象。五名居民仍使用项目人物原型图集，个人体型、服饰与原作精确肖像没有逐个重建。
