日期：2026-09-22。范围：`g15` 接受后、武当战已结束的回楼授职 → 地牢固定处决 → 客房离别 → 继位与孤独结局。数据为 `public/cult-staging.mjs`，由根代理汇入演出表；绘制使用 `public/renderer-v3.mjs`。地图、路线、任务奖励和执行/存档逻辑由其他模块负责。

## 已核验事件与原创表现

依据 [招揽参考核验](recruitment-reference.md) 中本地静态机制及攻略交叉记录：武当战后回摘星楼受任护法左使，再进地下；先蔷薇、后紫轩，均为固定处决，没有杀/不杀菜单，也不是普通敌人战。其后真儿返忘忧岛、月眉儿离去；后来纳兰潜凛练功身故，杨影枫继位、习成武道德经，最终孤独。当前证据不支持这一结尾额外发经书、装备技能或新取经战。

本次没有读取、提取或复制原游戏目录。场景和人物沿用项目独立制作的背景与人物图集；对白、演员位置、行走路线、剑光形状、倒下角度、光色、令符、独灯和动画时长全部重新设计。原版的具体动作、镜头、演员同屏次序和离场走向未核验。纳兰在地下段最后走到阶口离开，是为了保证后续回访状态合理的网页调度，不宣称原版有相同动作。

新增步骤：`strike:{actor,target,duration}`、`pose:'fallen'`、`hide:{actor}`。renderer 按当前步骤与持久 elapsed 绘制剑光、身体前倾和倒下；hide 不产生虚假“死亡经验”。`cue` 与 `wait` 表示授职、离去和时间变化。runner 保存动作步骤、演员位置、朝向、pose、hidden 与 cue；死亡/离去的剧情旗标仅在任务 release 后统一提交。

`finalActors`、`finalCues` 与 `persistFor` 负责回访展示。蔷薇段只延续到紫轩段；紫轩段的完整终态延续到告别、尾声。纳兰隐藏终态覆盖其地牢站姿，已完成结局后回访地牢也不会重新出现。

场景 NPC 的可选 `npcCell` 优先于通用人物映射；纳兰潜凛和无忧教执事的对白头像也映射至与现场相同的项目原创图格。

## 本子任务的真实浏览器验证

会话 `fullflow-cult-staging`，页面 `http://127.0.0.1:8787`，17 级普通难度。从 **`gCult_appointment` 授职前定点存档** 开始，武当完成条件属于初始 fixture；不将它声称为从 `g15` 招揽或游戏开局自然通关。初始设置后只用追踪按钮、继续对白、地面点击与舆图实际推进，没有修改后续 map、phase、死亡旗标或演员状态来制造成功。

1. 授职后仍处 `m61`，通过实际出口进入地牢；先蔷薇、后紫轩，两个触发点分开可达。
2. 蔷薇的出剑时实拍剑光；倒下后的对白中刷新，仍保持 fallen，再由 UI 完成该段。此时死亡旗标仅在 release 后出现；未提前写任务奖励。
3. 紫轩段开始仍能看到蔷薇倒地；第二次出剑和倒地后，两个死亡旗标均为 true。处决前后 kills 始终 0、银两始终 900，没有普通战斗经验/金钱回报。
4. 实际沿地牢出口进入客房。真儿走到门口隐藏后刷新，保存前后均为 `(1350,610), hidden:true`；眉儿仍在房内。继续对白后眉儿也走出，主角独留。
5. 尾声完成时 `ending:'cult'`、completed:true，两名受害者死亡、真儿/眉儿离去、纳兰身故与尾声完成旗标均已提交。companion 为 null，inventory 仍 `{}`、skills 仍 `{1:0,3:0}`，没有新增经书或可装备技能。五段完成/领奖记录各一次；结局刷新不重复提交。
6. 最初结局回访被通用 ending 分支拦住，根代理修复后，保持同一完成存档再次刷新并从舆图 **实际回到地牢**。两人仍倒地、纳兰不在场，靠近后交互提示隐藏，按 E 不显示对白。没有重置任务或地图。另修复空按 E 意外回落到默认出口的问题后再次实测：在 `(617,585)` 靠近蔷薇，按 E 并等待 1.7 秒，地图与坐标均不变、交互提示与对白仍隐藏。
7. 最终控制台 **0 errors / 0 warnings**。

紫轩段新增的“纳兰走到楼梯口后隐藏”两步在第一次浏览器过场之后补入；新增移动目标经路径验证可达，75 步恢复检查覆盖，且最终自然回访已目视确认隐藏终态。完整链代理随后使用最新代码继续验证，不把本次早期过场截图当作这两步的动态证据。
