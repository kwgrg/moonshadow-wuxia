# 从命分支婚礼梦与夜访：浏览器验收

## 初始条件与操作边界

这是章节定点验收，不是新游戏全程通关。一次性初始化 e06_night / r_evil_chamber / talk，明确从命杀害蔷薇且已回楼听完旧事。最初 fixture 的气血/内力高于其上限；正常 restoreState 将其钳制为 300/300、180/180，此后以页面实际值为基线，没有修改运行中数值。等级15、经验0、900文、木盒1、金创药5、灵药3、击杀0。

初始化使用同源一次性标记 qa-night-kill-once-v1，刷新时不再注入。之后只使用页面寻路/启程/继续按钮与浏览器刷新；没有调用引擎方法、重写坐标或演出步骤推进。单独 night-visual 会话用相同章节起点复拍最后界面修正。

## 实际经过与故障重试

1. 浏览器拦截 wedding-dream.png 并主动返回 ERR_FAILED。点击寻路，影枫实际走到客房休息点，入睡后尝试换景；页面提供“重新载入场景”。记录前后相隔1.5秒，存档均停在第7步 weddingDream、气血300内力180，未跳过背景或对白。
2. 移除图片拦截并点击重试，婚堂正常出现。第13步，影枫 (780,650)、蔷薇 (870,630) 分别可见，湖畔蔷薇和孟隐藏。此时刷新，前后都为第13步、weddingDream 和相同人物坐标，继续同一段对白。
3. 点击婚礼对白后，孟从右侧走至 (970,600)，出现追责对白。第一次截图发现对话用了蒙面人物肖像；修正姓名映射到本项目长者图格，随后重新载入并复拍。
4. 孟最后逼近点改为 (900,730)，避开蔷薇 (870,630)。真实演出到第21步出手，然后淡出、隐藏梦演员，返回现实客房第55步。主角 (760,665) 坐起，三个梦演员均隐藏，气血300内力180，没有普通战斗、击杀或掉落。
5. 继续后影枫在客房内徘徊，再走至门前 (1150,635) 交回操作，任务进入 e06_night_visit。此时只有 evilDreamEnded，没有 evilNightPassed。
6. 点击“启程前往”，观测到实际地图顺序 r_evil_chamber → m71 → r_zhen_chamber，落在新房门内 (750,820)。到房后尚未夜谈，需要再寻路接近真儿。
7. 真儿问蔷薇是否为影枫所杀；从命回应是回避和掩饰，不说拒杀支路的“没有动手、父亲逼迫”。随后约定翌日回岛，两人走离谈话点，夜谈结束才设置 evilNightPassed，进入 e06_escort，但仍在真儿房。
8. 再点击启程，实际返厅 m71 (490,435)，阶段 talk。最后刷新仍为 e06_escort / m71 / talk，没有重播梦或夜访。验收停止于辞行前，不把后续护送记入本轮实玩。
