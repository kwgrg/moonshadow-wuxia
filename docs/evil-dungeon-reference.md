## e04：战前认出，战后原谅

**静态已核验**：小筑到场时先有 11790–11840 的面对面对话，第一条已经由影枫直接认出紫轩，紫轩随后回应。之后才把紫轩设为敌对并转入战斗状态 Event595。击败她之后进入另一个回调，先说完战后对白，再给出原谅与不原谅的选择。

因此正确事件顺序是：**小筑赴约 → 认出紫轩并交谈 → 单挑 → 战后原谅选择 → 紫轩离开 → 当夜分支梦境/翌日返回**。现有网页“战后才揭名”说法需要更正；这项已经不只是两篇攻略与产品的冲突。

战前确认身份不等于庄外首次蒙面人袭击时就揭露身份；e03 的初次遭袭仍需保持其自身视角和时序。原版单挑数值、失败实机表现及梦境可控范围未在本次核验。

## 回楼到禁地：不可省略的关系

1. **回摘星楼会面**：地牢结果后转回楼内，“纳兰真”随后到场；纳兰谈及母亲、姐妹及两半玉佩与密室书信的关系。这里是获悉信息，不是给影枫两块玉佩或母亲信件。
2. **留宿与两种梦境**：从命分支梦到婚礼及孟知秋来报仇；拒杀分支梦到天池与蔷薇。脚本分别载入婚礼/天池情境后回到摘星楼夜间。梦中再次出现蔷薇不表示现实复活。
3. **夜谈，再约翌日回岛**：醒后需去找楼内“纳兰真”；两分支的问答分别受 KillQW1 控制，但都提出翌日回忘忧岛。不能把她写成已经在岛上等待主角，也不能让主角尚未商量就默认完成护送。
4. **翌日辞行与同行**：次日角色进入跟随状态，向纳兰辞行后出摘星楼至倚天山。原版状态到 Event3020，后续是带她经中原码头登船。纳兰此时留在摘星楼，并非同行上岛。
5. **船渡与海边**：船夫转场到岛上码头，再到海边。此时有切向摘星楼、孟知秋来战的旁线演出，随后返回海边。不能把这段镜头切换误作影枫本人回楼参战。
6. **睡醒后寻找，而非完成交付后自行离岛**：海边出现睡/梦/醒衔接和“纳兰真”离开。影枫醒后找不到人，去村落看到身影并尾随。原版脚本的特殊动作未实机播放；海边是否应具象展示行凶犹豫，不能仅凭资源编号断言。
7. **追踪到三层**：村落、连接图、禁地入口及一层继续追踪；到三层，假真儿分别在两个机关位置执行动作，开门后先入内，影枫随后跟进。不能将她提前变为月眉儿同伴，或让主角用自己包裹里未取得的两玉开门。
8. **读信，然后揭面，再战**：密室先保持纳兰真的外观读信；反应后揭面，表示切换为月眉儿，影枫才确认她的身份与姐妹关系。随后交战并由剧情败局进入 e07 招揽；月眉儿正式跟随在接受之后。

上述是已定位控制流与公开资料共同支持的因果次序；网页仍需自己制作可行走的分段地图和角色调度。原版所有连接图与跳转边没有在本次逐出口穷尽，不能把网页的直连邻接宣称为原地图拓扑。

### 尚未确认的冒名起点

密室由纳兰真表示切换为月眉儿，**此刻揭面**有明确静态证据。此前楼内和海边的演员及对白都以纳兰真名义运行，不能从显示名反推出真实身份。NBE 文末将楼中来客称为假扮者，但其细节另有已证错误，本轮未定位明确的抓走真儿、换面具或替换发生时刻。

因此应采用影枫当时的视角：楼内/同行阶段称“真儿”，密室才确认伪装。可以在开发资料标注“外观与自称”，不能擅自增加真儿被绑的现场，也不能断言海边离开的必定是真身或假身。两块玉佩如何具体从姐妹处汇到假真儿手中，亦未找到直接交付动作。
