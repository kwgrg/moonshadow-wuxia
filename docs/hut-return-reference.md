1. 两梦共同醒来后，恢复寒波谷现实配置，紫轩不在场。该段恢复离谷及数处连接图出口，更新行程提示并置 Event600。没有直接把主角送到摘星楼。
2. 回到悲魔山庄后，需要与蔷薇交谈。Event600 位于原 map030 的蔷薇对话包项，不是后期月眉儿夜谈事件。两篇攻略把会面具体置于大厅右厢房；NBE还描述铁云先说蔷薇心情不好。
3. Event600 安排主角与蔷薇交谈、相互移动；蔷薇向外走后被移除。攻略共同说明这是夫妻争执后蔷薇离家，不能在此刻直接宣布她已死、已被绑或生成营救战果。
4. 铁云接近主角并交谈，随后主角走回室内。事件暂置610，淡出后重新载入本庄角色，蔷薇仍被移除，再安排主角与铁云的次日交谈。攻略共同支持“一夜未归、派人寻找”，网页可使用房内渐暗和翌日醒来表达这次时间过渡。
5. 铁云先走向外侧又回来；随后真儿加入现场、走近，影枫跑向她。两人交谈后，真儿走离并被移除。她不是本段加入的同伴，也不应跟随影枫去摘星楼。
6. 真儿离开后，事件改置3000并更新救援行程，主角才动身赴倚天山摘星楼。该局部段没有 Choose、战斗/死亡回调、倒地结果、倒计时或资源发放调用；普通路途危险、等待期间玩家输入与原版存档粒度未核验。

消息主题由攻略交叉支持：真儿说纳兰抓蔷薇是为了胁迫孟知秋；NBE还记她求情受打、请影枫通知孟知秋，而影枫决定自己救人。她离开后的确切去处、抓捕现场与谁实际动手，本轮均没有新增核验，不能画成主角亲眼看见的过程。[NBE 邪线“小筑”至“摘星楼”段](https://www.nbegame.com/post/11646.html)、[杜胜利详攻略第60–62节](https://vv0817.neocities.org/gametxt/15_jxqysp)。
