# 善线通天塔至落叶谷夜宿：有界参考核验

核验日期：2026-09-24。范围为善线 Event2009 入塔、2010 救蔷薇返谷、2021–2027 安葬与夜宿分支，止于同意留下后抵达药王谷的2030入口，以及四拒后安葬蔷薇的2100出口。没有继续检查后续问医、解药或终局。本次是选定条目的静态核验，不是原版实机通关。

原目录只读；选择条目只在内存解码。没有保存原脚本、完整台词、NPC/对象配置、原坐标、地图、图片、音频或解包副本，没有建立导入器。下文为独立概述与定位元数据。网页如何分图、对白、构图、角色动作、碰撞、敌方属性、战斗保存与重试均须独立实现。

## 关键结论

1. **善线通天塔不是八场必须清敌的关卡。** 一至七层有敌人，但善线2009/2010的上下楼脚本没有敌数、首领死亡、开关或物品检查，没有关闭上下楼入口。敌人的死亡回调均为空。应允许绕过守卫上下楼；不能用“清光本层才能开楼梯”替代。
2. **第八层没有该善线守卫战。** 七层上楼进入的是原map049，而非map048；基础配置只有43个Kind6鼠，另由入口加入蔷薇。鼠没有敌对Relation或死亡回调，不能计作43名敌人。网页现有gTower8三敌战无此依据。
3. 在塔顶找到蔷薇，纳兰真已经被其父带走。蔷薇得知孟知秋重伤后要求返谷。亲吻或拒绝亲吻都合流到同行状态与Event2010；没有钥匙、羊皮、全清或其他物品门槛。
4. 携蔷薇逐层下塔、出沙漠返飞龙堡，再经地面路线回天山与落叶谷。已查节点没有塔顶直达落叶谷的传送。不能把顶层救人后直接切到孟墓前当作护送完成。
5. 回谷先在厅中面对已死的孟知秋，蔷薇停止跟随。与她交谈后才进行安葬，建立墓物并转至墓前，随后她短时重新跟随；再交谈才进入夜宿位置。不能把传功时仍活着的孟提前处理成死者，也不能略去本次返谷后的面对遗体和安葬。
6. 留宿有**四次**机会；任一次答应都进入同一留下分支。第一次、第二次、第三次拒绝后分别返回客房、听到再次呼唤，下一次须重新与蔷薇交互。第四次拒绝后另有是否探看哭声的选择，随后才进入不同死亡表现；不是第四拒立即把任务游标跳到悲魔山庄。

建议保留gTower1–8稳定ID，但把前七层改为到达并可自由上下楼的探索战斗，独立持久保存各层军阵；八层作为抵达救人位置，不配置虚构战斗。塔顶g19选择完成后开启蔷薇同行与真实下塔路线；前七层剩余敌人可威胁主角和同伴，不因救人、切层或回访自动删除。

## 实机护送后的独立平衡修正

根任务在浏览器连续下塔时发现，蔷薇会带着低生命进入下一层，而原网页药品与回血技能仅作用于影枫。为使护送可以合理持续，本项目新增**已清安全塔层按V调息同时治疗仍存活的蔷薇，每秒90生命，上限1200**。这是网页的独立可玩性适配，没有原版同伴疗伤机制证据，不应写作原版功能。没有改普通药品或技能的作用对象。

安全判定要求本层真实军阵与完整清场快照都匹配稳定ID、所有敌人已倒下且击败账本完整、战斗finished且不failed、处于after、主角和蔷薇均存活、无演出/暂停。只有实际开启打坐才增长；战中或只伪造finished、缺敌、重复ID、缺击败记录、缺/活敌清场快照均不能治疗，倒下者不能复活。治疗同步当前同伴、楼层军阵、清场快照及全程护送生命；每累计2秒实际治疗发一次存档事件，达到满血立即发一次，满血后不逐帧写入。根任务另外修正打坐开启时取消自动追踪目的地、待交互和攻击目标，避免V立刻被自动返程打断。
