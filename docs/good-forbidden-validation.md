## 证据与实现边界

[有界参考记录](good-forbidden-reference.md)区分已静态核验的事件条件与未知内容。已核的骨干为：证词后与蔷薇返岛，先检查空屋，禁地外场36敌全清后进入一、二、三层及密室，会合真儿与眉儿后原路退出，外场53敌伏击中任一三女败北或敌全清均进入押走场面，主角自己返岛码头并渡海后听铁云报告。

网页独立创作了全部对白、空间分室、背景复用、脚点、战斗属性、三人同行、束缚姿态、演出时长、存档格式和重试方式。本次没有新增原版素材、脚本、完整台词、配置副本或导入工具。此测试/部署审计没有访问原游戏目录；参考子任务的有界只读范围另见上述记录。

首战主角或蔷薇归零必须失败。第二战主角归零采用普通失败与重试，这是因原引擎跨图死亡回调覆盖优先级尚未证实而明确选定的网页适配。失败优先于同次处理中的全清或同伴受制，也属于独立调度合同，不冒称已核实原版同帧优先级。

## 实体路线与本轮发现

引擎行走记录确认以下路线实际经过可用相邻出口；逐帧移动线段不能穿越碰撞，旅行中保存保留地图、位置、目标与资源。命名船渡的即时跨图也检查实际邻接出口，不被当成任意传送。

1. 惠安镇 m59 → 惠安南郊 m41 → 中原码头 → 岛码头 m40 → 村落 m34 → 海边空屋。
2. 空屋 → m34 → m31 → 村北禁地山径 → m60外场。
3. m60 → 一层 → 二层 → 三层 → 密室；会合后完全按反向返回。
