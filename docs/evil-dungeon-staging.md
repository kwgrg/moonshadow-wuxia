# 邪线地牢选择：独立动作演出

范围：`public/evil-dungeon-staging.mjs` 的 `e06`、`e06_kill`、`e06_refuse`、`e06_aftermath`、`e06_night`、`e06_escort`、`e06_rest` 七段数据。模块导出 `EVIL_DUNGEON_STAGING`，由根代理接入主演出表、任务数据与 runner。本子任务不改原版目录，不新增战斗、掉落、奖励、分支决定或跨图传送。

遵守 [AGENTS.md](../AGENTS.md)。参考定位及原版静态核验见 [邪线地牢参考](evil-dungeon-reference.md) 与 [招揽路线边界](recruitment-reference.md)。本子任务使用核验代理提供的机制概述，没有读取或复制原版图像、动画、脚本、完整对白或引擎代码。

## 数据与 runner 契约

- `e06` 共 11 步：先完成实际走位和对白，最后 `release`。任务层必须保留 `type:'choice'`，release 只能进入选择，不能自动执行任何结果。
- `e06_kill` 共 16 步：`strike {actor:'hero',target:'qiangwei'}` → 蔷薇 `fallen` → 主角退开 → 纳兰走向南门并隐藏。
- `e06_refuse` 共 23 步：纳兰逼近 → 蔷薇自行移动 → `wallImpact` → 蔷薇 `fallen` → 主角走近查看 → 纳兰走向南门并隐藏。
- 两个结果均 `auto:true`，从选择后的实际主角位置开始动作；不设置 `heroStart`、不重放菜单、不给玩家伪造的战斗目标。
- `wallImpact` 的最小数据为 `{type:'wallImpact',actor:'qiangwei',direction:1,duration:.45}`。runner 仅保留演员朝向、累计并保存 elapsed，再推进步骤；没有攻击目标、HP 计算、伤害数字、经验、掉落或任务旗标提交。下一步独立 `pose:'fallen'` 决定倒下。
- renderer 应只对该演员向墙短促前倾，并在墙边出现少量灰尘；不画剑光、不让主角进入 attack。`fallDirection:-1` 让拒杀结果中的蔷薇朝墙外倒下，最终脚底仍位于可达点。
- 两结果的 `finalActors` 包含隐藏的纳兰与倒地蔷薇；`persistFlag:'evilQiangweiDead'` 配合 `persistentActors`，只长期投影已倒地且 `interactive:false` 的蔷薇。
- 长期投影必须同时要求本结果的 `staged_e06_kill` 或 `staged_e06_refuse` 已完成，以及 `evilQiangweiDead` 为 true；不能只看共享死亡旗标，否则可能读取另一分支的倒地位置。还须严格比较定义 map 与当前 map。
- 结果任务的互斥选择旗标、前置门槛、死亡旗标与奖领奖账本由任务层负责；本模块不提前写这些状态。结果只在最后 release 后完成，`cue` 是演出进度，不等于已发任务奖励。

初版 `persistFor` 列表已移除，以免过渡到楼内后再次回地牢时纳兰复现。原有 `gCult` 的 persistFor 行为不改。

## 回楼、夜谈、辞行与海边休息

- `e06_aftermath` / `m71`，13 步：主角实际返回楼内后走近父女；按当时显示身份称“纳兰真”。她展示随身半块玉佩，纳兰谈及亡妻、姐姐、姐妹各持半玉以及合玉打开禁地密门取母亲信件，随后影枫走向客房方向。玉佩只作 `jadeHalf` 演出道具，`jadeStory:'shown'` 时出现，不发给主角 inventory。
- `e06_night` / `r_evil_chamber`，21 步：主角坐下，灯色转暗，再梦醒自述；纳兰真在梦醒后由 `show` 出现在房门，实际走近夜谈，随后从门口走远隐藏。镜头没有蔷薇演员。本版仅用两句笼统梦醒自述与独处灯光表达睡醒，未将梦境指定为地牢；原版从命的婚礼/孟知秋报仇梦、拒绝的天池梦仍未完整演绎。
- `e06_escort` / `m71`，11 步：次日实际回厅辞行，纳兰真与主角走向楼口。release 后由任务奖励切换到真实跟随；模块不提前发 companion。
- `e06_rest` / `m34`，16 步：主角在海边 `(945,735)` 坐下入睡，纳兰真由 `(1055,720)` 经 `(1170,710)` 走向 `(1210,700)` 后隐藏，主角醒来起身。这里没有海屋、病床或幕后身份说明；清除 companion 由任务完成处理。

新增最小接口：`show {actor}` 仅解除该演员隐藏；hero 的 `sit` 必须实际绘制且随 `heroPose` 保存。`evilNight`、`evilMorning`、`shoreRest` 均为灯光/休息演出 cue，不是剧情奖励旗标。姓名“纳兰真”是现场当时显示名，不据此提前判断角色真身。
