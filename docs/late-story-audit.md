原攻略确认“有效左右随邪恶程度变化，错杆使全塔机关归位”。**数值 3 沿用当前网页的分支阈值，未得到原版脚本核实。拉索与回位簧线索为网页增加的可读提示，不是确认存在于原版场景中的物件。**

e13.requiredFlags 要求 switch1 至 switch8 全为真。数据本身不能防止越过前置条件，运行时必须执行该校验。

错误复位的接入要求：

- 清空全部开关标志，允许重新完成 eSwitch1–eSwitch8，并返回第一层机关任务。
- 已清理的塔层战斗不应重复刷奖励；跳过已完成战斗后仍可重新拨机关。
- 必须测试“第五层前开关已拨 → 第六层故意拨错 → 返回重拨 → 第二次成功 → 七八层 → 回五层解救”，确认无软锁。
- 换序后按 questId 恢复存档；只有旧数值索引的存档须有迁移，不能把 e13 误恢复成新第六层任务。
