# 邪线两梦与主动夜访演出

日期：2026-09-22。实现文件为 `public/night-dream-staging.mjs`，导出 `NIGHT_DREAM_STAGING`，已接入并覆盖 `e06_night`、`e06_night_visit`。运行器、场景、界面和 revision 7 迁移已完成集成。

## 证据与原创边界

依据 [禁地与夜梦核验](forbidden-pursuit-reference.md)。从命杀害蔷薇后进入婚礼梦：影枫与蔷薇相邻，孟知秋出现并逼近，短暂敌对后惊醒。拒杀后进入天池梦：两人先有距离，影枫跑近，蔷薇再向水边移动，画面淡出，影枫仍有反应。两支各自结束，不能顺次播放。

共同醒来发生在影枫自己的客房，包含室内徘徊。随后由玩家主动离开客房、经过厅堂，进入真儿所在的独立房间 `r_zhen_chamber`。两种现实选择对应不同夜谈，且两支真儿都先问蔷薇是否为影枫所杀。拒杀明确否认出手、提及纳兰父亲的施压，并另有走近动作；从命对现实责任作掩饰，不能写成向真儿坦承亲手杀害。谈毕才转翌日，再手动回厅辞行。真儿采用当时显示的姓名和外观，本段不提前判定其真伪。

背景 `wedding-dream.png`、`lake-dream.png`、`zhen-chamber.png` 均为本项目本轮独立生成的美术。人物继续使用项目原创图集：蔷薇为独立紫衣人物格，孟知秋为既有长者人物格。没有把它们声明为原作精确肖像或礼服重建。对白、坐标、速度、镜头焦点、明暗遮罩、剑光及等待时长均独立设计；本子任务未读取原游戏目录，也没有引入原素材、完整台词或脚本。

## 临时场景契约

- `e06_night.map` 固定为现实客房 `r_evil_chamber`。梦境通过 `scene` 步骤切换 `sequence.sceneKey`，不更改 `s.map`，不注册可旅行的梦境世界地图。
- 定义白名单 `sceneKeys: ['weddingDream','lakeDream']`。`scene` 步骤携带该场景的主角位置和朝向；共同醒来使用 `scene:null` 恢复现实落脚点。
- 三个梦中演员使用独立 ID `wedding-rose`、`lake-rose`、`dream-meng`，初始均隐藏，并各有对应 `sceneKey`。现实灯具有 `sceneKey:null`。场景过滤与恢复白名单由运行器落实，避免被破坏的隐藏状态把死者显示到现实客房。
- 分支中的每一步，包括切图、显示、对白、移动和等待，均带自己的现实结果 `when.flag`。正常存档仅允许 `evilQiangweiKill` / `evilQiangweiRefuse` 恰有一个成立。两者不能同真，也不能为新流程凭空猜测一个结果。
- 显式迁移的未知旧档使用 `evilLegacyDreamUnknown`，可以跳过梦境到共同醒来；夜访采用另写的中性衔接，条件要求该迁移旗标且两个结果旗标均不存在。这不能被记录为已观看某个具体梦境，也不追补现实死亡原因。
- `dreamFade:'out'|'in'` 为画面遮罩；`dreamThreat:true|false` 为短暂压迫表现。孟使用既有 `strike` 动画指向主角，不建立敌人、HP、击杀、死亡回调、掉落或胜利结算。
- 所有梦中演员在回房前隐藏；`finalActors:[]`，没有 `persistFlag`、`persistFor` 或永久演员投影。现实 `evilQiangweiDead` 及地牢倒地演员不由梦境步骤改写。
- 演出自身不发经验、钱、同伴、玉佩或发钗。`release` 仅交回任务结算，夜谈结束后才能进入既定翌日辞行任务。
