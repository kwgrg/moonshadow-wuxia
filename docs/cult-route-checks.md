# 正转邪路线验收边界

本轮围绕 g15 接受招揽后的武当战、回楼授职、地牢两段事件、客房离别与最终独居结局建立可行走链。剧情证据沿用 docs/recruitment-reference.md；本文不新增未经核验的原版地理事实。

## 独立场景设计

- m61 明确为摘星楼议事厅，复用本项目原创 hall 画面，并重新布置厅堂、廊柱和门口。纳兰位置 845,445；地牢出口 1270,730，进入厅堂的位置 1135,680。
- r_cult_dungeon 使用本轮文字生成的原创 cult-dungeon 画面。左右两单元位于 650,610 与 1020,570，中央隔断保留南北两条绕行通道；近身点 575,655 与 940,620。地牢连厅堂与客房，双方出口/入口分别设置，抵达不会自动原路跳回。
- r_cult_chamber 使用原创 bedroom 画面和独立陈设。共同离场门在 1350,610，角色可经 1050,600 走到门边；最终独坐点为 690,455。
- 以上坐标、隔断、演员距离和门的方位均为网页表现设计，不是原版地图复制或实测。原版具体房间比例、相邻关系、建筑高度与镜头未确认。
- 原 g16 的救援事件仍复用 m61；厅堂更名并不代表其关押地点问题已获解决。

## 需要保持的机制

1. g15 接受不立即结算 cult；只有武当战和其后全部事件完成才进入结局。连续拒绝保留正常正线救援；无邪线或弃情线串入。
2. 条件 notAll 的含义是列出的全部旗标均为假。portal 候选须枚举独立旗标组合，尤其 cultPath=true、forsake=false。
3. 39 名敌方与 27 名友方属于同一场阵营战；清除记录、双方状态和生命持久化。未全部清除不能授职；单个角色倒下不产生可重复刷取的钱或经验。
4. 战败重试完整重开当前战斗，不延续死亡阵容。结束奖励只领取一次。
5. campaignRevision 升为 4。旧数字索引分别使用 revision 3、revision 2 与原始任务快照；questId 优先。旧立即 cult 结局档保留历史已完成状态，不强行撤销，也不把它计作新链验收。旧 g16 拒绝档继续救援；现代进行中存档不会因此获得结局。
