# 禁地两玉开门与读信揭面：独立演出

范围：`public/forbidden-staging.mjs` 导出 `FORBIDDEN_STAGING`，提供 `e07_gate` 与 `e07` 两幕数据；根代理负责接入主演出表、任务门槛、renderer、runner 和存档迁移。场景与人物只用本项目独立制作的素材，不读取或导入原游戏资源。

## 已核机制与原创表现

依据 [AGENTS.md](../AGENTS.md) 与 [邪线地牢参考](evil-dungeon-reference.md)。两处机关动作、开门后先入内、读信后反应与揭面以及随后交战，均有只读静态核验支持；这里不复用原动作文件或完整信件对白。

| 已核事件 | 本网页独立表现 |
| --- | --- |
| 假真儿分别在两处机关作动作，开门后先入内；影枫注意到两块玉佩。 | 仍显示“纳兰真”的演员左座用玉，再横过门厅到右座用玉；两座亮起、门打开，她先走入门洞后隐藏。影枫随后靠近，才说出关于两玉的观察；玩家再实际跟进。 |
| 密室仍保持纳兰真外观读信，反应之后才切换为月眉儿。 | 外观演员由入口走向深处木箱，定时 `readLetter`，随后以纳兰真的显示名反应。`replace` 原地替换之后才出现月眉儿姓名、头像和对白。 |
| 读信、开门没有将两玉或母亲信发给主角。 | 半玉和纸页只作为演员手部演出；模块没有 handover、inventory、奖励、消耗或技能操作。 |
| 揭面之后才交战，败后才有招揽选择。 | 月眉儿走到独立备战位置再 release，由根代理的任务层直接开始战斗。本模块不提供招揽菜单，不产生胜利或失败结果。 |

具体对白、玉光、门扇、手部动作、画像与木箱美术、空间坐标、速度和时长都由本项目独立设计。楼内来客开始冒名的准确时间、两半玉佩的具体转移及真儿被带走的过程未核实，因此这些不在演出中补写。

## 最小步骤与持久契约

- `useJade {actor:'zhen',socket:'left'|'right',duration:1.2}` 只推进当前演员的动作与 elapsed；`jadeLeft:true` / `jadeRight:true` cue 在各次动作完成后保存。两次使用不读取或扣除主角的玉佩。
- `gateOpen:true` cue 在两次动作之后设置，驱动门扇开启及当前演出的通路放行；不可只等待 quest 奖励 `evilGateOpened`，否则演员无法在 release 前先入门。玩家的下一图入口仍须遵守任务层门槛，不能凭单个未经完成的 cue 绕过开门任务。
- `finalCues` 保留双座与开门状态；`persistFlag:'evilGateOpened'`、`persistentActors:[]` 在回访时保持门开且不再生成此前已经进去的身影。还必须满足该幕 staged 完成键。
- `readLetter {actor:'zhen',duration:1.7}` 后设置 `letterRead:true`，接着先播放读信反应。读信 cue 是恢复进度，不能代替已败战或已答应加入飞龙堡。
- `replace {actor:'zhen',target:'mei'}` 应在一次可保存的步骤中把坐标与朝向从旧演员复制到新演员，再 hide 旧、show 新；恢复后不能出现双人、恢复旧姓名，或让新演员返回其隐藏初始点。
- `mei` 初始 hidden、`enemy:true`，揭面后可见。释放战斗时，舞台演员必须退出显示，只保留战斗数组中的月眉儿，避免两名月眉儿重叠。
- 门内 actor 的 y 为 210，restore 必须接受当前场景的合法北侧坐标；若沿用 y>=300 的旧夹取，会把入门中途存档拉回门外。应按新场景可行区域验证。

`e07_gate` 为 20 步，`e07` 为 24 步。阶段中没有跨地图 step，只有当前地图内的路径移动；两幕之间由玩家实际穿过相邻入口。

## 验收状态与保留缺口

模块语法与 diff 格式检查通过。新地图 mask 落地后，在明确开门的几何 fixture 下，用实际 GameEngine 逐 5 像素检查所有演员初始点、移动目标、起点与门户：264 条有向路径通过，门厅 132、密室 132。该路径检查只证明开门条件下的通行，不代替关门门槛和中途中断事务检查。根代理还须覆盖两次用玉、门开、入门隐藏、读信反应、replace、战斗和拒绝死亡的中途保存恢复，确保不重复给予道具或提前跳过交战。图面核对和数据步骤数量不证明全流程复刻，当前文档也不把背景预览当成游戏内浏览器验证。
只读参考审查后又修正两处：两玉观察已移至门开、身影入门隐藏、影枫靠近之后；月眉儿对白只确认信里的姐妹关系，删去“今日才知道”的无证首次知情断言。此调整不改变坐标、任务奖励或 20 / 24 步总数。门厅最终关键顺序为：左玉 → 右玉 → gateOpen → 入门 → hide → 影枫靠近 → 两玉观察 → release。
