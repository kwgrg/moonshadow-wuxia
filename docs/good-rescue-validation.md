# 善线救援集成验收（revision 14）

2026-09-24。本报告记录三拒招揽后厅堂突围、地下救紫轩、护送回谷、救眉儿、返庄与飞龙堡至沙漠的独立网页实现验证。测试使用人工章节状态、边界HP和真实引擎方法；不是原版实机记录，也不是浏览器从开局连续通关。不能由人数、任务总数、模拟结局或29组检查宣称完整复刻。

## 证据边界

[有界参考核验](good-rescue-reference.md)负责区分原脚本显式条件与未知细节：厅堂44敌必须清完才可下楼；地下存在28敌，但紫轩交互不要求先清场；救出后余敌未被清除，紫轩随行返空楼并亲自送回寒波谷定点安置；途中27追兵的关键友军眉儿败北会失败，获救后她自行离开；其后另有山庄56敌和飞龙堡56敌。

网页独立制作了场景、碰撞、脚点、人物表现和对白，独立选择战斗属性、演出期间暂停、失败重试、存档和奖励事务。地下救援失败后明确重试会重启本次地下救援、重新出现28敌并让紫轩回到待救状态；这属于网页适配，不冒称原引擎行为。尚未核实的原版精确动作、几何、AI、隐式暂停、存读档与回调优先级仍保持未知。

本测试与部署审计没有访问原游戏目录，也没有复制原资源或增加导入工具。[本轮前置现状审计](good-rescue-current-audit.md)记录修改之前的缺口和候选方案；其中已经被当前明确合同替换的旧人数、旧捷径、室内安置候选不作为当前实现描述。

引擎专项逐帧检查实际旅行，不将“任务目标图”当作已经到达。旅行保存恢复不改变位置、钱物或任务；移动线段不得穿越碰撞。当前独立网页路线如下，并不声称等于原地图的精确数量、比例和布局。
