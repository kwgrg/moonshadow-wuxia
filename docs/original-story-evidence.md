## 1. 开场的动作、动机与空间

地图 `map_002_凌绝峰峰顶.map` 的 `Begin.txt`（目录项 `4bf40813`）呈现的是一段完整的墓前演出：跪姿、父子关系与练武动机、起身、向外行走，之后才交由玩家选择难易度并展开旅程。

墓前位置为地图格 `(24,39)`，离开演出点为 `(24,43)`。这两个位置是原版地图格坐标，不能直接当作旧网页版场景的像素坐标。容易模式有明确的起始等级提升，而不是仅减少敌人伤害。

独立实现应保留这段“先建立关系与目标，再接管角色”的节奏，使用新写的对白与自制动作。现有版本让玩家围着墓碑找任务点，不能等同于这段开场。

## 2. 地图不是任务背景轮播

最初的路径依次经过凌绝峰峰顶、凌绝峰连接山路、武当山下、洗剑池、登山连接图、武当山顶。武当山下还连接前往惠安方向的路线。它们应形成带有岔路、出口、入口和剧情通行条件的空间网络。

独立实现优先恢复“朝一个方向走，进入下一段地形”的连续性。地图追踪应提示方向或规划走路路径；不能用按钮直接跳到下个剧情点来代替旅行。地图出口尚未开放时，提示与退回位置应一致，不能让主角在提示后穿过去。

## 3. 酒肆是动机发生的现场

武当山下的区域触发脚本（目录项 `1b2ac890`）安排主角先行至 `(9,101)`，随后靠近老板 `(8,92)` 问路，再靠近酒客 `(8,93)`。两名酒客的交谈使主角产生挑战名门、追求声名的动机，本段结束之后才出现武当目标。

老板的常规交互与酒客的剧情旁听是不同的状态。原版还有取药材等支线条件；它们依赖前置进展，并不是任意地点放置的随机宝箱。

独立实现需要：人在桌旁、主角转向并靠近、旁听有先后、事件仅发生一次。对白应重新创作，不能直接使用提取台词。

## 4. 洗剑池有两个触发阶段

碑文触发与守卫阻拦分别由不同区域处理，定位目录项为 `4337ce33`、`5c7a1853`。守卫为两名，分别靠近 `(22,18)` 和 `(22,19)`，主角进入对峙位置 `(21,21)`。这不是接一个任务后原地生成三名通用敌人。

战斗结束条件也有明确含义：两名守卫都被击败后，才安排撤退、恢复通行与向山上推进（目录项 `debc1b9f`）。战斗进行中不能通过出口离开。重建时应让玩家看见路径被谁阻挡，打完后又因什么而开放。

## 5. 武当试剑不是五人群战

武当山顶存在十名不同的普通弟子：清虚、清水、清微、清霄、清灵、清玄、清云、清越、清河、清木。玩家逐个发起切磋，普通弟子挑战胜利累计至少五场后，才开放张惟宜的挑战条件（目录项 `282d9109`）。

因此，修正前版本“普通弟子五人一波，再接大弟子一波”的实现虽然能通关，却改变了原版的交互、节奏与场景用途。应重建选择对手、走到对方面前、交谈、进入单场切磋、结束后恢复交互的循环，并阻止对已击败目标重复计数。

进一步核对了死亡回调绑定时点：只有满足五场胜利门槛并开始挑战张惟宜时，才绑定武当特殊败北处理（目录项 `282d9109`）；普通弟子挑战未改写主角死亡规则。败给张惟宜后才推进阶段、恢复山顶非敌对NPC配置、更新后续对话并恢复常规死亡规则（目录项 `b4f0af13`）。回调没有清零胜场；这一阶段已经结束，既有胜场不再用于继续挑战。

普通弟子挑战失败应走常规死亡路线，而不是立刻进入下山剧情或无代价继续选人：原版通用死亡回调（目录项 `47b10cd2`）结束后返回标题，找到的杨影枫角色配置均引用该默认规则，普通弟子挑战脚本没有另行绑定失败处理。该结论来自静态数据；封装的 `rpg0` 初始人物存档未直接解出，也没有实机试败，仍需后续实机验证这一细节。

独立实现不能把这几种失败结果混在一起，也不能将失去控制后的强制扣血当成完整切磋。

## 独立重建的优先次序

1. 先恢复六段主路线与岔路的可步行地图拓扑，验收出口与入口，而不是先加更多背景图。
2. 为酒肆和洗剑池写位置触发、NPC走位、朝向、临时锁定输入与恢复输入的演出系统。
3. 增加十名独立交互的弟子，并实现逐场胜利记录与五场门槛。
4. 分开普通死亡、剧情败北、挑战胜利及退出时的行为，验证存档恢复后仍符合当前阶段。
5. 用浏览器录制实际操作，检查走路、遮挡、人物落脚和战斗窗口；流程模拟只验证逻辑，不能证明场景与操作达标。
